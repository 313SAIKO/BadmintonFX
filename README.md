# BadmintonFX

โปรเจกต์ JavaFX + Maven สำหรับโจทย์ระบบจองสนามแบดมินตัน (แบบฝึกหัด OOP 2569)

## วิธีเปิด
1. เปิด IntelliJ IDEA แล้วเลือก File > Open > `C:\Users\khump\IdeaProjects\BadmintonFX`
2. รอ Maven โหลด dependencies (JavaFX 21.0.6)
3. เปิด `src/main/java/org/example/badminton/BadmintonApplication.java`
4. Run `BadmintonApplication`

หรือใช้ Terminal ที่โฟลเดอร์โปรเจกต์:

```powershell
mvn javafx:run
```


ข้อความ `WARNING: sun.misc.Unsafe ...` ตอนรันไม่ใช่ error เกิดจาก JavaFX 21 ทำงานบน Java รุ่นใหม่ ไม่มีผลกับโปรแกรม

## เข้าสู่ระบบ

- ผู้ดูแลระบบ: `A01`

## ลองใช้งาน
- **ส่วนลดชั่วโมงที่ 20:** เข้าระบบด้วย `C01` แล้วไปที่แท็บ "จองสนาม" พิมพ์ `M001` ในช่องค้นหาสมาชิก (มีชั่วโมงสะสม 18 ชม.) เลือกวันที่ 2026-10-12 แล้วคลิกช่องสนาม 3 เวลา 18:00 ตามด้วยช่อง 20:00 จะเห็นยอด 414.00 บาท (180 + 54 + 180)
- **ตารางสนาม:** คลิกช่องสีเขียวช่องแรก แล้วคลิกช่องสุดท้ายในสนามเดียวกัน (หรือกดค้างแล้วลาก) เพื่อเลือกหลายชั่วโมง คลิกช่องที่เลือกไว้ซ้ำเพื่อยกเลิก ปุ่ม « » ใช้เปลี่ยนวัน
- **ค้นหาสมาชิก:** พิมพ์รหัส ชื่อ หรือเบอร์โทร ถ้าเหลือคนเดียวระบบจะเลือกให้อัตโนมัติ หรือดับเบิลคลิกสมาชิกในแท็บ "สมาชิก" เพื่อไปจองให้คนนั้น
- **แพ็กเกจ:** สมาชิก M002 มีแพ็กเกจเหลือ 13 ชม. ถ้าจองจะหักจากแพ็กเกจ และช่องแนบสลิปจะซ่อนไป
- **ตะกร้าอุปกรณ์:** แท็บ "เช่า/ซื้ออุปกรณ์" ดับเบิลคลิกอุปกรณ์เพื่อใส่ตะกร้าได้หลายรายการ ปรับจำนวนด้วยปุ่ม − / + แล้วกดยืนยันครั้งเดียว หลังจองสนามสำเร็จ กดปุ่ม "เช่า/ซื้ออุปกรณ์ให้ ... ต่อ" จะกรอกชื่อลูกค้าและวันที่ให้
- **รายงาน:** เข้าระบบด้วย `A01` แท็บ "สรุปรายได้รายเดือน" จะมีกราฟรายได้แต่ละวัน แยกสีตามหมวด
- **วันหยุดนักขัตฤกษ์:** วันหยุดไทยบางวันนับตามจันทรคติหรือประกาศเป็นปีต่อปี จึงต้องให้ผู้ดูแลระบบกรอกเอง ที่แท็บ "วันหยุดนักขัตฤกษ์" เพิ่มหรือลบวันหยุดได้ ถ้าทำให้การจองที่มีอยู่เกินเวลาทำการ ระบบจะแสดงรายการจองและเบอร์โทรสมาชิกให้ยืนยันก่อน และตารางสนามของแคชเชียร์จะแสดงการจองนั้นในแถวสีเทา
- **เปลี่ยนสมาชิกระหว่างจอง:** ถ้าเปลี่ยนไปเลือกสมาชิกคนอื่น ระบบจะล้างเลขที่สลิป ไฟล์สลิป และผลการจองของคนก่อน กล่อง "จองให้:" จะบอกเสมอว่ากำลังจองให้ใคร

## ไฟล์สำคัญ
คลาสของระบบ (เหมือนเวอร์ชัน console):
- `Person.java` (abstract) คลาสแม่ของ `Member` / `Cashier` / `Admin`
- `Item.java` (abstract) คลาสแม่ของ `RentalItem` / `SaleItem`
- `Chargeable.java` (interface) ใช้กับ `Booking` / `HourPackage` / `ItemOrder` ทุกอย่างที่ทำรายได้
- `Court.java`, `OpeningHours.java`, `PaymentSlip.java` ส่วนประกอบของระบบ
- `CartItem.java` รายการในตะกร้าอุปกรณ์ ใช้กับ `Cashier.sellItems()` เพื่อเช่า/ซื้อหลายรายการในครั้งเดียว
- `BadmintonCenter.java` เก็บข้อมูลทั้งหมดของศูนย์
- `SampleData.java` ข้อมูลตัวอย่าง

หน้าจอ JavaFX:
- `BadmintonApplication.java` จุดเริ่มต้นโปรแกรม และสลับหน้าจอ
- `login-view.fxml` + `LoginController.java` หน้าเข้าสู่ระบบ
- `cashier-view.fxml` + `CashierController.java` หน้าแคชเชียร์ มีแท็บจองสนาม สมาชิก แพ็กเกจ อุปกรณ์ และค้นหา
- `admin-view.fxml` + `AdminController.java` หน้าผู้ดูแลระบบ มีแท็บประวัติการจอง รายได้รายวัน/รายเดือน และวันหยุด
- `FxHelper.java` เมธอดช่วยที่ใช้ร่วมกัน เช่น สร้างคอลัมน์ตาราง และกล่องยืนยัน
- `style.css` สีและรูปแบบของหน้าจอ
